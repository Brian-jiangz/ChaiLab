CESM CoSiNE16+5 (CoSiNE22) 耦合说明书

概述

本文档描述 cesm_cosine_v2 源码树中 CoSiNE16+5（实际 22 个示踪物）在 CESM2.1.5-POP2 中的实现与运行流程。V2 版本在 V1 的基础上进行了重要扩展：

  • 在原始的 16 个 CoSiNE 示踪物基础上，增加了 DOC、DO13C、DO14C、DI13C、DI14C 五个碳同位素相关示踪物，共 22 个
  • 使用自维护的 CESM 源码树（cesm_cosine_v2），基于 cesm2.1.5-rc.01
  • BGC 模块仅使用 CoSiNE16，不激活 MARBL/ecosys
  • 初始场制作更复杂，需将 MARBL 格式的初始场转换为 CoSiNE16+5 格式

源码树位于 HPC 集群：

/fs2/home/fchai02/model/CESM/cesm_cosine_v2

Case 脚本模板位于：

/fs2/home/fchai02/resource/case_templates/BCoSiNE_v2

V1 → V2 主要变化

| 项目 | V1 (cesm_cosine_v1) | V2 (cesm_cosine_v2) | |------|---------------------|---------------------| | 源码树 | 官方 CESM2.1.5 | 自维护 fork (cesm2.1.5-rc.01) | | 示踪物数量 | 16 (CoSiNE16) | 22 (CoSiNE22) | | 附加示踪物 | 无 | DOC, DO13C, DO14C, DI13C, DI14C | | OCN_TRACER_MODULES | iage cosine16 | iage cosine16 (但无 MARBL) | | Case 命名 | e21.b1850.CoSiNE.test.* | e21.b1850.CoSiNE22.test.* | | IC 制作 | 简单转换（7 个变量） | 完整转换（14 个变量） | | 源码位置 | manage_externals 管理 | 直接嵌入 POP2 源码树 |

状态变量

CoSiNE16+5 携带 22 个预报示踪物：

其中前 17 个示踪物与 V1 的原始 CoSiNE16 一致，后 5 个为 V2 新增：

| 索引 | 名称 | 含义 | 单位 | |------|------|------|------| | 18 | DOC | 难降解溶解有机碳 | mg C/m³ | | 19 | DO13C | DOC 的 ¹³C 同位素 | mg C/m³ | | 20 | DO14C | DOC 的 ¹⁴C 同位素 | mg C/m³ | | 21 | DI13C | DIC 的 ¹³C 同位素 | mg C/m³ | | 22 | DI14C | DIC 的 ¹⁴C 同位素 | mg C/m³ |

CESM 源码树结构

cesm_cosine_v2 是一个完整的 CESM 源码树（git 仓库），基于 cesm2.1.5-rc.01。CoSiNE16 模块直接嵌入 POP2 源码：

cesm_cosine_v2/
├── cime/                    # CIME 框架
├── cime_config/             # compset/PES 配置
├── components/
│   ├── pop/
│   │   ├── source/
│   │   │   ├── CoSiNE16_mod.F90      # 主模块（含 22 个示踪物）
│   │   │   ├── CoSiNE16_parms.F90    # 参数文件
│   │   │   ├── ecosys_driver.F90     # 驱动（co2 flux 等）
│   │   │   ├── ecosys_tavg.F90       # 时间平均
│   │   │   └── ...                   # 其他 ecosys 支撑模块
│   │   └── externals/
│   │       ├── MARBL/                # MARBL 子模块（保留但未激活）
│   │       └── CVMix/
│   ├── cam/
│   ├── clm/
│   ├── cice/
│   └── ...
└── doc/

CoSiNE16 模块与 POP2 的耦合通过 passive_tracers 框架实现。在 ecosys_driver.F90 中，cosine16_set_interior 计算内部源汇项，cosine16_set_sflux 计算海气通量。.false.。

数值耦合方案

CoSiNE16 示踪物作为 POP2 被动示踪物注册。其控制方程与 V1 相同：

其中平流扩散由 POP2 处理， 由 cosine16_set_interior 计算，海表通量由 cosine16_set_sflux 计算，沉降通量在模块内部处理。

在初始化时，cosine16_init 注册示踪物名称、单位、参考值、重启行为和 advection 方法：

ecosys_tadvect_ctype     = 'base_model'
tadvect_ctype_module(:) = ecosys_tadvect_ctype
